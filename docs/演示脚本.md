# 演示脚本（课程答辩 / 5 分钟）

> 目标：在 5 分钟内展示一个**可运行、可复现、边界清楚**的本地化预检闭环，而不是展示“AI 什么都能做”。所有演示数据均为合成数据。

## 0. 演示前 2 分钟准备

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v          # 预期：Ran 104 tests ... OK
python3 app.py --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。页面会自动载入中→葡演示。

演示环境：

- 本机 Python 3.9+ / Pillow 11；
- Chrome 或 Edge；
- 默认无 `LLM_API_KEY`，因此顶部显示“确定性模式 · LLM 未配置”；
- 如果需要演示 live LLM，提前设置 `LLM_API_KEY` 并在页面勾选“LLM 语气建议”，但要说明这只影响 `REG001`。

## 1. 开场（20 秒）

“这是一个课程级可运行原型。它不替代 CAT/TMS，也不声称解决目标语语法。它只把三件事放到同一份可导出报告里：模板完整性、给定字体/布局假设下的宽度风险、以及有证据来源的语义线索。”

指着顶部副标题：

> 课程级可运行原型 · 确定性检查为核心 · 不把“测过的模板”说成“已验证的语法”

## 2. 总览（30 秒）

页面默认载入 28 条中→葡合成数据。

讲解 6 张汇总卡：

- 28 条文本；
- 9 个阻断错误 / 9 条文本；
- 9 个需复核 / 6 条文本；
- 3 条渲染溢出（另有 1 条 ICU 模板未测、1 条空译文）；
- 消歧弃答 0；
- 15 条需人工处理。

强调：**“通过”只表示已实现的检查项未命中，不是目标语语法通过。**

## 3. 核心一：2px 的宽度风险（60 秒）

打开：

```text
http://127.0.0.1:8000/?demo=zh_ptbr&unit=settings.tab.settings
```

展开 `settings.tab.settings`，指出：

- `Configurações` 在 110×36px、内边距 6px 的 `settings_tab` 盒模型中，内容区 98×24px；
- Pillow 实测最宽行 100px，超出 2.0px；
- 字符数基线给出 114.4px / 2 行，方向一致，但**不是同一件事**；
- 浏览器 DOM 实测同样判溢出，与 Pillow 一致；
- 下方列出假设：Noto Sans Regular、字号 16、字距 0、按词换行、不模拟引擎布局、不支持自动缩放/富文本/fallback。

主动说明边界：

> “这不是说游戏里一定溢出。它只说明：在这个字体、字号、字距、文本框和换行假设下，宽度不够。最终要在目标引擎里确认。”

再指 `long.banner`（38.4px）和 `event.year` / `map.island`：

- `MMXXV` 字符基线说“可容纳”，字体测量说溢出（假阴性）；
- `Ilha` 字符基线说“溢出”，字体测量说可容纳（假阳性）。

一句话：**字符数只能预警，字形测量才能暴露这两类误判；但字形测量仍不是引擎布局。**

## 4. 核心二：模板完整性（45 秒）

依次展开：

- `placeholders.missing`：源文 `{0}`，译文缺失 → `PH002` error；
- `placeholders.extra`：译文多出 `{1}` → `PH003` error；
- `placeholders.printf`：`%s/%d` 重排/类型变化 → `PH005` error；
- `placeholders.icu_missing`：葡语 plural 缺 `other` → `PH008` error；
- `tags.imbalance`：`<b>` 未闭合/标签集合不一致 → `PH006/PH007`。

强调：

> “这些是确定性规则，不依赖模型。它只验证变量保留、重排合法性、ICU 分类完整性、标签闭合；它不判断目标语该用单数还是复数。”

如果想展示反例，打开 `mail.claim_all` 的 `PH012` 提示：

> “`{0} 封邮件` 提示可能存在数量影响，但源码里没有复数格式。工具不会替你猜目标语语法，只提示需要上下文。”

## 5. 语义辅助与弃答（70 秒）

切换到英→葡：

```text
http://127.0.0.1:8000/?demo=en_ptbr
```

先指出同一个 `Rank` 在不同上下文的三条结果：

- 排行榜 → `Classificação`；
- 军衔 → `Patente`；
- 品质 → `Qualidade`。

再打开弃答样本：

```text
http://127.0.0.1:8000/?demo=en_ptbr&unit=misc.rank_unknown
```

指出：

- 没有 key/screen/neighbor，三个候选都是 0 分；
- 结果不是硬猜，而是 `CTX001` + “证据不足，已弃答”；
- 给出需要补什么：screen、相邻文案或人工指定。

然后展示错误义项样本：

```text
http://127.0.0.1:8000/?demo=en_ptbr&unit=lore.setting.entry
```

`Setting` 在世界观词条里应译 `Ambientação`，译文用了 `Configurações`，触发 `CTX002`。

主动说明：

> “义项库只有 7 个合成词条，证据打分也可能错；所以它被标成实验性，并且保留弃答路径。它不是 Agent 理解了文本。”

## 6. 源文缺口与修辞（35 秒）

打开：

```text
http://127.0.0.1:8000/?demo=zh_ptbr&unit=dialogue.next_level
```

指出 `SRC001`：中文“点击确认后，将进入下一关”省略了主语；工具输出“需要问什么”，而不是替译者补全。

再指 `status.unlock` 的 `SRC002`：

> “短状态词‘解锁’缺少时态/体信息；按钮组件会跳过这条规则，避免把按钮文案误报。”

最后指 `register.sarcasm` / `register.meme`：

> “讽刺/梗只做风险提示，建议人工确认语域。LLM 也只在这里做旁路建议。”

## 7. 批量流与导出（40 秒）

在页面点“导出 CSV”或“导出 XLIFF”；说明导出内容：

- CSV：扁平行，便于表格/回导；
- XLIFF 1.2：`trans-unit` + 上下文/问题 note；
- JSON：完整报告，含证据、假设、引擎边界、LLM 状态。

命令行演示（可提前跑好）：

```bash
python3 scripts/check.py data/demo_zh_ptbr.json --out out/demo --target pt-BR
python3 scripts/check.py data/demo_zh_ptbr.json --out out/demo --fail-on error; echo $?
```

预期：第一条输出 `文本: 28 条 / error=9 warning=9 info=16` 并生成三个文件；第二条退出码 1，可接 CI。

说明元数据来源：

> “key/screen/component/neighbors 来自现有字符串导出、界面路径、同屏文案；UI 盒模型来自设计稿或引擎配置。缺失时显示覆盖率并标‘需上下文’，不要求译者逐条填表。”

## 8. 收尾（20 秒）

> “这个原型的可验证部分是模板完整性和给定字体假设下的宽度风险；消歧、源文缺口和修辞是实验性辅助。它没有厂商访谈，也没有商业 A/B，所以只声称课程级可运行原型。下一步如果要验证价值，应该用真实项目字符串做小规模任务测试，而不是继续堆规则。”

## 9. 常见追问与回答

**Q：CAT/TMS 已经有预检，为什么还做？**

A：同质化部分确实存在：占位符、长度、术语、报告。这个原型的增量假设是把“测量假设”和“证据/弃答”显式化，并且能单机复现；但没有证明商业优势，见 `docs/方案比较.md`。

**Q：Pillow 宽度能代表游戏内溢出吗？**

A：不能。它是给定字体/字号/字距/文本框/换行假设下的风险测量；不模拟引擎布局、自动缩放、富文本内联样式和 fallback。最终以目标引擎实测为准。

**Q：为什么不用 LLM 直接判断？**

A：不确定性、成本和不可复现；课程验收需要可测试的核心。LLM 只作为语气建议的旁路，无 Key 自动降级。

**Q：为什么 `{0}` 不判断复数？**

A：没有变量语义、目标语规则和模板格式时，猜语法就是过度声称。工具只验证保留/重排；需要上下文时输出提示。

**Q：为什么俄语样本说“无法测量”？**

A：ICU plural 模板要按运行时分支渲染后才能测；直接测模板字面量是假测量，所以显式返回 `OVF000`。

**Q：数据是真的吗？**

A：不是。项目、文案、UI 尺寸、义项库都是合成演示，已在页面和文档标注；没有厂商访谈或真实项目数据。

## 10. 失败兜底

- 端口占用：`python3 app.py --port 8001`。
- Pillow 未安装：`python3 -m pip install -r requirements.txt`；没有 Pillow 时字体测量不可用，不要继续声称已测量。
- 浏览器字体未加载：等页面字体加载完成，或看 `document.fonts.check('16px "Noto Sans"')`；截图前确保字体已加载。
- LLM 未配置：保持未勾选；这本来就是默认演示路径。
- 不想现场跑命令：提前把 `docs/测试报告.md` 的实际输出和 `docs/evidence/` 截图放在演示稿里。
