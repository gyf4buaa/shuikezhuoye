## 6. 未验证 / 明确限制

- **没有真实 API Key**：未向 DeepSeek 或任何真实供应商发起调用。live 分支只由注入 fake transport 的单测覆盖；没有把 fake 结果当作真实译文展示。因此真实模型质量、网络兼容性和计费行为尚未验证。
  - 为验证 Web 端 live 渲染，内部曾用本地 stub OpenAI-compatible 端点跑通一次 A/B 卡片交互；stub 输出未进入仓库、截图或 PR 证据，不作为真实模型结果。
- **没有真实游戏工程**：只在 `demo_project/` 合成 C# 工程验证，未接入 Unity、真实字符串导出或 CAT 工具；不能据此声称可自动处理任意真实游戏语义。
- **启发式不是编译器**：类/方法定位与语境分类是轻量规则，复杂 C# 语法、反射、运行时拼接、动态加载未覆盖。
- **未做人工翻译审校**、未做多模型对比、未评估术语一致性。
- 仓库当前没有配置 CI workflow；以上为本地实际执行结果，不表述为“CI 通过”。
