边界与限制

  • 这是合成演示工程上的小型 PoC，尚未证明能在任意真实游戏中自动找到完整语义。
  • 检索基于字面 Key / 文本与文件扫描，不分析复杂数据流、反射、字符串拼接或运行时格式化。
  • 界面语境推断是确定性的标识符/注释词元启发式，不是编译器或语义分析；可能误判，证据不足会标为需人工确认。
  • 同一文本可能属于多个 Key：未直接引用所选 Key 的命中会标为“同文本候选”。
  • 未配置 SOURCEAWARE_API_KEY 时绝不调用模型、绝不显示 AI 译文；配置后为真实调用，但未做人工审校。
  • 只读访问 demo_project/，带路径边界保护；默认只监听本机，不发送真实企业源码。
